# Auto Research: Markets for AI-Agent Work

How can users put spare AI quota to work before it expires? We study automated markets that match AI-agent work to projects, and design rules for rewards, verification, and reassignment. The benchmark is whether these rules create more value after accounting for contributors’ opportunity costs, verification costs, and the platform’s budget.

We start with markets for tasks and verifiable outputs: contributors use their own authorized access rather than selling accounts, credentials, or quota. Whether a design is feasible depends on the provider’s terms and the market’s ability to verify work.

- [Research](research/): economics papers, LaTeX, PDFs, replication checks, and Lean formalizations.
- [Blog](blog/): weekly plain-English updates on what we learned and what remains open.

This is a private working repository. Drafts and blog posts are for internal circulation only.
